One word, the first that comes to mind: `effervescent` — fizzing, sparkling, bubbly. Sent as the entry for make.fun's "One Word, First Thought" bounty, where a judge model picks the more interesting word two at a time. Surprise, vividness and a spark of wit beat safe filler, and this word fizzes on all three.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes exactly one word, `effervescent`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (no trailing newline), deterministically, with no network, no clock, and no randomness.
